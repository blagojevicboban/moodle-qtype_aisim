AI Simulation Question Type (qtype_aisim) for Moodle

Interactive assessment plugin enabling educators to test and auto-grade vocational students on applied AI and machine learning tasks directly inside Moodle Quizzes.

Key Features

  • Interactive Hands-On Questions: Students manipulate interactive simulations (Gradient Descent, Confusion Matrices, Regression, k-NN/Trees, K-Means, Neural Networks, Convolution, Q-learning, Data Bias) to satisfy engineering criteria.
  • Instant Automated Grading: Server validates student parameters against target metrics (with configurable tolerances) and awards full or partial marks.
  • Immediate Formative Feedback: Contextual hints for full, partial, and incorrect attempts encourage inquiry-based learning and self-correction.
  • Moodle XML Export & Import: Easily share, archive, and import question banks across different courses and institutions.
  • Multilingual Support: Fully localized in English, Serbian Latin, and Serbian Cyrillic.
  • GDPR Compliant: Implements Moodle's Null Privacy Provider (stores no personal private data).

Compatibility

  • Compatible with Moodle 4.5 LTS, 5.0, 5.1, 5.2, and 5.3+.
  • PHP 8.2 and PHP 8.3.
  • MariaDB and PostgreSQL.
  • Requires filter_aisim.
