AI Simulation question type

Quiz questions in which students solve a task inside an interactive machine learning simulation, graded automatically.

Live demo: try the plugins on aisim.tsp.edu.rs. Log in as a guest, or use the demo accounts teacher and student (to take the quizzes), password Demo-2026. Everything is reset every night.

What's new in 1.0.0

  • Stable release: thirteen simulation types, each with its own targets and half marks.
  • Four new simulation types: logistic regression, cross-validation, data preparation and the recurrent neural network.
  • Ready-made questions: 39 questions, three for each simulation.
  • Teacher guide 1.5: in English, Serbian, Slovak and Portuguese.

Features

  • A task in a simulation: the teacher picks one of the thirteen simulations, the scenario and the target, for example a recall of at least 0.80 with a precision of at least 0.70, or a test accuracy with at most four hidden neurons.
  • Automatic grading: Moodle grades the values the student reached, with a tolerance the teacher sets and half marks for a partial solution.
  • Feedback: separate feedback for correct, partially correct and incorrect answers.
  • Review: the simulation opens in the state the student left it, with the controls locked.
  • Ready-made questions: 39 questions, three for each simulation, in a Moodle XML file in the repository.
  • Moodle standards: backup and restore, Moodle XML import and export, PHPUnit tests.
  • Translatable: all texts are language strings and can be translated in AMOS.

The AI simulation plugins

  • AI Simulations Viewer (filter_aisim): runs the simulations; required.
  • AI Simulation button for TinyMCE (tiny_aisim): inserts the simulations in any text.
  • AI Simulation question type (this plugin): quiz questions graded automatically.

Requirements

  • Moodle: 4.5 LTS to 5.3.
  • filter_aisim: 0.10.0 or newer.

Privacy

The plugin stores no personal data beyond the quiz attempts that Moodle keeps, and sends nothing to external services; it implements the Moodle Privacy API.

About

Developed in the Erasmus+ project AI for VET for vocational schools. The teacher guide, the question bank, the source code, issues and the changelog are in the GitHub repository.
